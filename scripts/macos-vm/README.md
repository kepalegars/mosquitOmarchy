# macOS VM module (`scripts/macos-vm/`)

Run macOS in a QEMU/KVM virtual machine on Omarchy, from the
[OSX-For-Omarchy](https://github.com/28allday/OSX-For-Omarchy) project
(vendored here, commit `d8cd6f4`).

## What the module provides

- Interactive installer — `osx-kvm-installer.sh` — that installs the heavy
  dependencies (qemu-full, libvirt, edk2-ovmf, samba, dmg2img/cdrtools via yay, …),
  clones [OSX-KVM](https://github.com/kholia/OSX-KVM) into `~/VMs/macos/` (grouped with the other VMs under `~/VMs`, override with `MOSQUITO_VM_ROOT`), downloads the
  macOS recovery image, creates the disk, OpenCore/OVMF config, per-VM launcher and
  desktop entry, and offers shared Samba folders + USB passthrough.
- A gum-based VM manager TUI — `macos-vm-tui.sh` — to create / delete / inspect VMs
  (multiple VMs, different macOS versions, deterministic SSH port each).
- Menu entry **Setup > macOS VM**, with the TUI window
  floating centered (800x600). No global keybinding is registered.

## Usage

```bash
setup-customarchy.sh macos-vm            # or run in a module selection
scripts/macos-vm/setup-macos-vm.sh       # idempotent; --remove to clean (keeps ~/VMs/macos)
~/.local/bin/osx-kvm-installer.sh        # first VM (or use the TUI)
# TUI: menu Setup > macOS VM, or 'macos-vm-tui' in a terminal
```

## Differences from upstream (why the vendored copy differs)

- The three scripts are self-locating — no hardcoded `/home/mosquito/...` paths, so they
  work from `~/.local/bin` or any clone directory.
- The upstream installer appended its keybinding as `bindd`/`windowrule` into
  `~/.config/hypr/bindings.conf`, which does not exist on Omarchy (it uses
  `bindings.lua`). That step is now a no-op. **No global keybinding is
  registered** — the manager is opened from the Omarchy menu (Setup > macOS VM).
  The **window rule** stays in the module's own marker block:
  `-- >>>/<<< Omarchy_Custom_Scripts_MacosVm` in `hyprland.lua`.
- The TUI/launcher files are generated by the installer when it runs; they now point at
  the deployed location instead of the author's clone directory.

## Requirements

- Omarchy (Arch + Hyprland), KVM (`/dev/kvm`, VT-x/AMD-V in BIOS), ~64 GB free disk per VM
- `gum` — installed automatically by `setup-macos-vm.sh` (the TUI and installer use it)

## First boot

1. OpenCore menu → "macOS Base System" → wait for Recovery.
2. Disk Utility → erase the QEMU HARDDISK as APFS ("Macintosh HD").
3. Reinstall macOS (30–60 min, several reboots), then boot "Macintosh HD" in OpenCore.

See the upstream README (in `OSX-For-Omarchy`) for details, troubleshooting (KVM/black
screen/network/SMBIOS) and the macOS version support table.
